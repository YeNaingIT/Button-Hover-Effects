Button Hover Effect

This project is a simple demonstration of a button with hover effects using HTML and CSS.
🔗 View the Demo
📁 Files Included

    index.html – Main HTML file with a sample button

    style.css – CSS file containing hover styles for the button

💡 Features

    Clean button design

    Smooth hover transition

    Easy to customize

🛠️ How to Use

    Clone the repo or download the files.

    Open index.html in your browser.

    Modify the styles in style.css as needed.
